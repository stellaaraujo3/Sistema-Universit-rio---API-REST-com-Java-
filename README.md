# Sistema Universitário

Este projeto foi iniciado em 2025 como atividade acadêmica da disciplina de Programação Orientada a Objetos em Java.

O objetivo inicial era desenvolver um sistema simples para aplicar conceitos fundamentais como CRUD, organização em camadas e integração com banco de dados.

Com a evolução do projeto, o sistema passou a ser ampliado para uma arquitetura mais próxima de aplicações reais, utilizando backend com API REST e frontend separado.

## Tecnologias utilizadas

Backend
- Java
  
Frontend
- HTML
- CSS
- JavaScript

Banco de dados
- PostgreSQL

## Funcionalidades

- Cadastro de alunos
- Listagem de alunos
- Atualização de dados
- Exclusão de registros
- Integração entre frontend e backend via API REST

## Objetivo do projeto

Este projeto tem como objetivo praticar desenvolvimento backend, construção de APIs REST e integração com frontend, simulando o desenvolvimento de um sistema real.
